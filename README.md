# Path of the Wild

Working title for a native Android exercise-driven monster-catching RPG.

Real-world walking feeds an actual RPG: verified steps provide Adventure Points for overworld discovery and a modest amount of character XP. The game is being built in Kotlin with Jetpack Compose and is designed to adapt across phone, tablet, foldable, landscape, portrait, and resizable Android windows.

## Current playable foundation

- Adventurer character creation
- Health Connect step status/read permission shell
- Direct Android step-counter status/live reading
- Character-time fitness baselines so old steps do not count
- Adventure Point and walking-XP preview from post-character steps
- Persistent tile exploration prototype
- Simple wild-monster encounter prototype
- Manual calorie log and daily target
- Fitness diagnostics screen with multiple counters
- Responsive bottom-navigation / navigation-rail shell
- CI debug APK build

See `docs/ROADMAP.md` for the broader approved design and `docs/RESPONSIVE_UI.md` for device-layout rules.
